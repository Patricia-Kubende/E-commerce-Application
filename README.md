# E-commerce-Application
to implement a search functionality that allows users to quickly find products based on specific keywords

1. Designed the HTML structure, including a search bar and a section for displaying product results.
2. Implemented JavaScript functionality to filter and display products based on user input.
3. Created a CSV file to store product data, which will be used to populate the application.

Type of Functionality Accomplished This Week:

The main functionality developed  includes:
- Search Feature: Users can enter keywords into a search bar, and the application dynamically filters and displays matching products. This functionality enhances the user experience by allowing environmentally conscious consumers to quickly find products that align with their sustainability values.
- Data Integration: Established a method to store and retrieve product information using a CSV file, making it easy to manage a small dataset.
